# Heimdall Home Lab

A clean public documentation workspace for the Heimdall home-lab project.

## Purpose

This repository will hold reviewed architecture notes, project context, runbooks, diagrams, and supporting scripts. Content will be added only after review and authorization.

## Documentation rules

- Keep public documentation free of passwords, tokens, private keys, recovery codes, and personal data.
- Do not publish private network-access details or unreviewed configuration exports.
- Separate confirmed results from plans, proposals, and unresolved items.
- Record the scope and date of verification when describing operational behavior.

## Repository structure

- `architecture/` — reviewed system structure and boundaries
- `projects/` — individual project context
- `runbooks/` — reviewed operational procedures
- `diagrams/` — approved visual documentation
- `scripts/` — reviewed, publishable automation

This repository currently contains documentation scaffolding only.
